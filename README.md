# SmartPantry AI

SmartPantry AI is an intelligent pantry management and meal recommendation application developed as a graduate capstone project for Full Sail University. The system helps users reduce food waste, organize pantry inventory, and discover meal recommendations using AI-driven ingredient matching and nutrition analysis.

The application combines pantry tracking, expiration monitoring, recipe recommendations, grocery unlock suggestions, and nutritional analysis into one streamlined interface.

---

# Features

## Pantry Management
- Add pantry items
- Edit pantry inventory
- Delete pantry items
- Track quantities
- Track expiration dates
- Organize items by category

## AI Meal Recommendations
- Detect recipes based on current pantry inventory
- AI ingredient matching system
- Suggest complete meals and partial meal matches
- Recommend meals using expiring ingredients first
- Display missing ingredients needed to complete recipes

## Nutrition Analysis
- Calories
- Protein
- Carbohydrates
- Fat analysis
- Meal type classification
- Cuisine classification
- Dish type classification

## Grocery Unlock Suggestions
The system recommends grocery items users can purchase to unlock additional recipes and meal opportunities.

## Dashboard Analytics
- Pantry health score
- Inventory overview
- Expiration tracking
- Food category distribution chart
- Expiring item alerts
